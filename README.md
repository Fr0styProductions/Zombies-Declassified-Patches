# Zombies-Declassified-Patches
Zombies Declassified-Patches is a bug fix for the release of ZD/Zombies Declassified which is a bo2 dlc 5 port to black ops 2 plutonium this fixes most of the bugs in the current releases!

Installation:
1. Open Run and paste this into the prompt %LOCALAPPDATA%\Plutonium\storage\t6\ then press ok
2. Copy the mods folder inside of the zip
3. Paste the mods folder in the folder that run opened.
Thats it, there will be a installer soon.

UnInstallation:
1. Open Run and paste this %LOCALAPPDATA%\Plutonium\storage\t6\mods\dlc5\
2. delete mod_patch.ff
Thats it should be finished!

There will be more releases soon
